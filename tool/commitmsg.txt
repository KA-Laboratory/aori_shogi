配布は Cloudflare R2 に決めた（int4 で小さくするのは断念）

まず「本当に 1.90GB なのか」を潰した。潰せなかった。

- dynamic_wi4_afp32 → 1.04GB（45%減）。Play の asset pack 上限 1.5GB にも収まるが、
  日本語が壊れる。制御トークンが1語ごとに本文へ割り込む。
- dynamic_int4_block32 は export_hf では使えない（KeyError）。パッケージ内に名前は
  あるが別の場所のもので、export_hf が受けるのは dynamic_w{i8,i8c,i4,i4c}_afp32 と
  dynamic_wi8_emb4_afp32 だけ。
- dynamic_wi4c_afp32（チャンネルごと）は通るが、壊れ方が wi4 と同じ。ファイルは
  別物（sha256 が違う）なのに実機の出力は「thought thought 口thought…」まで同一。
  4bit にした時点で同じように壊れる。

1.90GB は動かせない前提で、配布先を Cloudflare R2 に決めた。
- いまの install() が URL から落とす作りなので、model_catalog.dart の URL 差し替えだけ。
- egress 課金が無いので「広まって請求が来る」が構造的に起きない。保存も無料枠内。
- iOS でも同じ経路が使える（PAD は Android 専用で、2分割も要る）。
Hugging Face はモデルカード（Qwen3 Apache 2.0 の出所表示）として併用、実配信は R2。
