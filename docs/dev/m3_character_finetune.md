# M3 追加計画: 軍師キャラの追加学習（LoRA）

作成: 2026-09-17 opus-5（賢太郎さんの指示で M3 に追加）

## 目的
端末内 LLM（flutter_gemma + Gemma 4 E2B/E4B）が、プロンプトだけに頼らず「自称・天才軍師」の口調と性格で安定して話すようにする。
雑談＋記憶（python/aori_lab/smalltalk.py）と口調制御（assets/lines/gunshi_tone.json）の Dart 移植と同じ M3 で行う。

## 根拠
- 約500発話・3〜5エポックの小規模ファインチューニング＋few-shot がキャラクター性で最良。エポックを増やすと文法が崩れる。モデルサイズ差は小さい（中路・狩野, NLP2025）。
- 語尾はモデル内部から制御しにくい（高橋ら, NLP2025）→ 追加学習後も **口調の規則処理（gunshi_tone.json）は安全網として残す**。

## 学習データ（約500本）
1本 = {気分, 場面, 事実（形勢・直前の手・煽りの図星判定など）, 相手の発言, 軍師のセリフ}。
配分の目安（気分5 × 場面）:

| 場面 | 本数 |
|---|---|
| 着手時のひとこと（move） | 60 |
| 煽りが図星／外れ（taunt_hit / taunt_miss） | 80 |
| 褒められた・褒め殺し・警戒（praised / praise_flood / praise_suspicious） | 50 |
| 自分の悪手・相手の悪手（blunder_self / blunder_player） | 50 |
| ボロ（本当／嘘）・読みを聞かれてはぐらかす（slip / question_dodge） | 50 |
| 持ちかけ（一手待ってやろうか・置き直し・取引・引き分け）と返事 | 50 |
| 雑談（smalltalk、記憶に触れる／聞き返す） | 80 |
| AIか聞かれてはぐらかす・不適切発言をたしなめる | 30 |
| 開始・勝ち・負け | 50 |

- 大混乱（meltdown）は乱暴な言葉も可（人間味。2026-09-17 オーナー判断）。です・ます・女性語・人称のぶれは全気分で不可。
- 50本を評価用に取り分け、学習に使わない。
- **データの書き手（要決定・下記「利用規約の注意」）**。

## 学習と組み込み
1. PC（RTX 3070 Ti 8GB）で QLoRA（PEFT/Unsloth）。Gemma 4 E2B と E4B の両方。3・5エポックを比較。
2. 変換: LoRA 重みを分けて LiteRT 形式へ（ベースモデルは一度だけ DL、アダプタは数十MBで差し替え可能）。
   - **要確認**: LiteRT-LM（.litertlm / Gemma 4）のセッションで LoRA を読む公開 API は整備途中（google-ai-edge/LiteRT-LM #1188, PR #2508）。使えない場合はマージしてから変換（アダプタ差し替えは不可になる）。
3. flutter_gemma で読み込み、few-shot（テンプレートから5本）＋口調チェック＋規則処理は継続。

## 受け入れ条件
- 評価用50入力で、口調の崩れ（tone_eval 相当、規則検出）: 追加学習なしより減る。規則処理後の崩れ 0%、テンプレート落ち ≤ 5%。
- キャラらしさ: 追加学習あり/なしを伏せて並べ、賢太郎さんが判定（あり が過半数で勝つ）。
- 文法崩れ: 目視 50本中 3本以下。
- 実機 Galaxy S24 で 1発話 p95 < 6秒（E2B/E4B）。
