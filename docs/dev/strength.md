# 棋力レベル（2026-09-18）

人間が自分に合う強さを選べるように、感情の変調とは別の「棋力レベル」を入れた。
数値は `shared/skill_levels.json`（Dart `lib/core/mind/move_policy.dart` と Python `aori_lab/policy.py` が一致していることをテストで確認）。

| レベル | 基準温度 | 候補手 | 思考時間の倍率 |
|---|---|---|---|
| 入門 beginner | 900 | 10 | 0.3 |
| やさしい easy | 600 | 8 | 0.5 |
| ふつう normal | 350 | 6 | 0.8 |
| 強い strong | 120 | 5 | 1.2 |
| 全力 allOut | 30 | 3 | 2.0 |

温度が高いほど最善から離れた手を選ぶ。**感情（平静さの欠け・焦り）の分はこの基準温度に足す**ので、
同じレベルでも煽られて崩れれば弱くなる。焦っているときは候補手が3つ広がる。

## 測った結果（`python/tools/strength_ladder.py`、感情なし・1手100ms基準・1組8局・全80局）

勝率（行が勝った割合）

| | beginner | easy | normal | strong | allOut |
|---|---|---|---|---|---|
| 入門 | - | 1/8 | 0/8 | 0/8 | 0/8 |
| やさしい | 6/8 | - | 0/8 | 0/8 | 0/8 |
| ふつう | 8/8 | 7/8 | - | 1/8 | 0/8 |
| 強い | 8/8 | 8/8 | 7/8 | - | 0/8 |
| 全力 | 8/8 | 8/8 | 8/8 | 8/8 | - |

1手あたりの平均損失: 入門166cp / やさしい127cp / ふつう93cp / 強い50cp / 全力24cp。

レベルはきれいな階段になっている（上のレベルが必ず勝ち、平均損失も単調）。
**人間にとってどれが適切かは未確認**。アプリで実際に指して、勝ったり負けたりするレベルを見つける必要がある。
目安として、1手あたり100cp以上損する相手（入門・やさしい）はアマチュアでも勝ち筋が見えるはず。

## 残っていること

- 実機・エミュレータで人間が指してみて、初期値をどのレベルにするか決める（今の既定は「ふつう」）
- 思考時間の絶対値（`PolicyParams.baseMovetimeMs` = 1500ms）を端末の速さに合わせて見直す
- 感情の分（温度 +最大700）が強すぎないか、レベル別に確認する
