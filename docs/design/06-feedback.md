# 音・触覚・画面演出

この文書で確定したこと
- 効果音は8ファイル、BGMと軍師ボイスは0ファイルとする。
- 駒の操作は乾いた木音、会話は軽い打音で区別する。
- 終局・王手・提案を優先し、同時イベントを重ねすぎない。
- 音量0・触覚OFFでも同じ情報を文字と形で伝える。
- 同じイベントの再描画では音・触覚・演出を再実行しない。

策定日: 2026-09-20。実装前仕様。関連: [共通モーション](03-visual-system.md)、[HUD判定](04-hud.md)、[画面](05-screens.md)。本書は発注と実装の指定であり、音源制作・聴取検収は未実施。

## 調達する音源

音源はオリジナル録音または合成、権利条件はCC0-1.0で納品。第三者サンプルを無断流用しない。根拠: 出典不明の効果音をアプリへ含めない。作者・権利者・作成日・ライセンスを `ASSET-LICENSES.md` に記録する。

共通形式はPCM WAV、48,000Hz、16bit、mono。アプリ用パスは `assets/audio/{id}.wav`。前後の無音は各10ms以下、クリック防止fadeIn5ms/fadeOut20ms、ピーク−3dBFS以下、DCオフセット絶対値0.001以下。音量設定60で再生倍率0.6、0では再生しない。根拠: 小さな短音は圧縮率より遅延と再生の安定を重視する。

| id | 尺 | 質感・強さ | 流用するイベント |
|---|---:|---|---|
| `piece_pick` | 60ms | 指が木に触れる軽いコツ、鋭い高域を抑える | 駒選択 |
| `piece_place` | 100ms | 乾いた木のパチ、短い余韻 | 着手・捕獲 |
| `piece_promote` | 180ms | 木のパチ＋短い明るい1音 | 成り |
| `notice` | 160ms | 中音域の木打音2つ、警報のように繰り返さない | 王手・提案・口滑り |
| `taunt_hit` | 180ms | 小太鼓を指で弾く軽いポン、破裂音なし | 煽り成功 |
| `taunt_miss` | 100ms | 低めの鈍いコト、嘲笑声なし | 外れ・逆効果 |
| `result_win` | 650ms | 木琴の上行3音、祝福、金属の長い残響なし | プレイヤー勝利 |
| `result_loss` | 500ms | 木琴の下行2音、静かな締め | 敗北・中立終局 |

尺合計1,930ms、PCMデータ185,280bytes、44byteヘッダー×8を加え185,632bytes。アプリ納品上限は8ファイル合計200KiB=204,800bytes、各ファイルの付加メタデータは除去する。WAV8個＋権利表1個の計9ファイル。根拠: サイズを算術で見積もれ、BGM・ボイスで膨らませない。

素材の相対音量はplaceを基準とし、pick=0.45、promote=0.8、notice=0.7、hit=0.8、miss=0.5、win/loss=0.7を再生倍率に掛ける。最終音量は端末で聴取し、クリップ・耳障りな高域・操作音間の極端な差がないことを検収する。根拠: ピーク上限だけでは聴感が揃わない。

## トリガ表

優先度は0が最優先。触覚はFlutter `HapticFeedback` の `selectionClick` / `lightImpact` / `mediumImpact` / `heavyImpact` に対応。noneは呼ばない。非対応端末は無音・無振動で正常継続する。

| イベント | 音（id・尺） | 触覚 | 画面演出 | 優先度 |
|---|---|---|---|---:|
| 駒を持つ（新しい選択） | piece_pick・60ms | selectionClick | 選択駒の枠と合法移動先を即時表示 | 4 |
| 駒を置く（合法手の確定） | piece_place・100ms | lightImpact | 最終手の角括弧を新しい着手先へ移す | 3 |
| 駒を取る（合法手確定） | piece_place・100ms、倍率1.0 | mediumImpact | 持ち駒枚数を即時更新、着手先角括弧 | 3 |
| 成る（確定後） | piece_promote・180ms | mediumImpact | 駒の成り字へ即時置換、輪郭180ms fade | 2 |
| 王手（新しい局面で成立） | notice・160ms | mediumImpact | 状態帯に「王手」、玉に2dp二重枠を解消まで保持 | 1 |
| 詰み | 勝敗に対応するresult音、最大650ms | heavyImpact | 「詰み」＋勝敗カード、盤を参照表示に | 0 |
| 投了（確定後） | 勝敗に対応するresult音、最大650ms | mediumImpact | 「投了」＋勝敗カード | 0 |
| 煽りが刺さった | taunt_hit・180ms | lightImpact | [04](04-hud.md)の実差分、強い負差分だけ顔の揺れ240ms | 2 |
| 煽りが外れた | taunt_miss・100ms | none | 「効かなかった」＋実差分、1,800ms | 3 |
| 煽りが逆効果 | taunt_miss・100ms、倍率0.8 | selectionClick | 「余裕を取り戻した」＋戻り矢印・実差分 | 2 |
| praiseが反映された | none | selectionClick | 「冷静↑・慢心↑」と実差分 | 3 |
| 変化なし | none | none | 「変化なし」、数値0 | 4 |
| 軍師が口を滑らせた | notice・160ms、倍率0.6 | selectionClick | 発話に「口が滑った…？」を恒久追記 | 2 |
| 軍師が提案してきた | notice・160ms | mediumImpact | 盤直上に返答待ち、下部交渉領域を180msで開く | 1 |
| 提案を受けた | piece_pick・60ms | selectionClick | 実際のcontroller結果へ更新、返答待ち解除 | 2 |
| 提案を断った | piece_pick・60ms | selectionClick | 提案解除と「断りました」1,800ms | 2 |
| 気分が変わった | none | none | 表情180ms fade、気分名即時更新 | 4 |
| 軍師が長考に入った | none | none | thinkingが2,000ms継続したら「軍師が一手を思考中」＋3点 | 4 |
| 対局開始 | piece_place・100ms、倍率0.6 | lightImpact | 「対局開始」1,200ms、手番と時計は即時表示 | 3 |
| プレイヤー勝利 | result_win・650ms | 原因の触覚を採用、未定義原因はmediumImpact | 「君の勝ち」、smugではなく敗北した軍師のmeltdown | 0 |
| プレイヤー敗北 | result_loss・500ms | 原因の触覚を採用、未定義原因はmediumImpact | 「軍師の勝ち」、軍師のsmug | 0 |
| 引き分け | result_loss・500ms、倍率0.5 | lightImpact | 「引き分け」、軍師のcoverUp | 0 |
| human / aiBoth終局 | result_loss・500ms、倍率0.5 | mediumImpact | 先手／後手の勝ちまたは引き分け、顔なし | 0 |

無効なタップや未確定の成り候補には着手音を鳴らさない。王手表示は音が省かれても必ず残す。対局開始・提案解除などの通知は盤の上にToastを重ねず、状態帯か下部領域に出す。根拠: 見たい駒を演出で隠さない。

## 同時発生と重複抑制

同じ着手に含まれるイベントは、終局＞王手＞成り＞捕獲＞通常着手の1音・1触覚にまとめる。例: 駒を取りながら成って王手をかけた場合はnotice1回。詰みと勝利は同じ終局としてresult_win1回と原因に対応する触覚1回。画面上の確定結果と必要な枠はすべて表示する。

着手以外の同時イベントは80ms窓で最小優先度の1音を採用。同順位は提案＞口滑り＞煽り＞その他、さらに同種は最新1件。低順位の音を後からキュー再生しない。触覚の間隔は最低150ms、音は同時最大1、上位音が来たら現在音を20msで停止して新音を鳴らす。根拠: 連続会話で音が渋滞しない。

ゲーム識別と実イベント（着手番号＋種別、lastTauntの新規結果、pendingOfferの出現、resultの出現）で1回だけ発火する。時計tick・画面再表示・テーマ変更・LLMの同じ発話への置換では再生しない。終局画面から戻って結果カードを開き直しても再演出しない。根拠: Widgetのbuildをイベントとみなさない。

## ミュート・バックグラウンド・低減

| 条件 | 動作 | 根拠 |
|---|---|---|
| 効果音0 | 音を開始せず再生中も停止、テキスト・触覚は設定どおり | 完全無音を選べる |
| 触覚OFF | HapticFeedbackを呼ばない | 音とは独立した選択 |
| OSが音を抑制 | OSの指示に従い、独自に音量を上げない | 端末の静音操作を尊重 |
| 他アプリの音楽再生 | 長時間の音声フォーカスを取らず、音楽を停止させない | 短い操作音のために音楽を中断しない |
| アプリが非アクティブ | 新しい音・触覚・装飾の開始なし、復帰時の溜まった再生なし | 復帰時に過去の対局音を聞かせない |
| OS/アプリの動き低減 | 揺れ・点滅を止め、状態の文字は即時更新 | モーションだけを減らす |
| ファイル欠損・再生失敗 | 該当音を省略、対局を継続、製品UIに例外文字列を出さない | 音をゲーム進行の依存にしない |

長考表示はエンジンの `thinking` にだけ結びつける。LLMの4,600ms待機には長考音やリトライ音を作らず、即時の定型文を維持する。[04](04-hud.md)の状態区別を守る。

## 検収

8ファイルの形式・尺・合計容量を機械検査し、実機のスピーカーとヘッドホンで全8音を通して聴く。重複終局・連打・バックグラウンド復帰・音量0・触覚OFF・音源欠損で確認する。無音かつ無振動でも、王手、煽り結果、交渉中、終局が文字と形だけで区別できれば情報面の合格とする。
