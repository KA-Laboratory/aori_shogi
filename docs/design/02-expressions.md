# 軍師・表情差分発注書

この文書で確定したこと
- 原画差分は5枚、Moodの5値と1対1で対応させる。
- 胸上の同一構図、透過WebP、72dp用の1x・2x・3xを納品する。
- 勝敗・思考・交渉の専用絵は追加せず、既存5枚とUIの表示を使う。
- 顔文字と画像は同じ72dp枠で交換し、読込失敗は顔文字に戻す。
- 揺れは顔だけに限定し、盤・駒・操作領域は動かさない。

策定日: 2026-09-20。実装前の発注仕様。依頼元: [指示書](../dev/design_brief_for_codex.md)。関連: [キャラクター](01-character.md)、[共通モーション](03-visual-system.md)、[HUD](04-hud.md)。本書だけで画像を発注できる条件を以下に全記する。

## 人物と共通構図

人間の成人男性、32歳相当、細身、4頭身の設定。胸上・正面から画面右へ10度、プレイヤー目線、髭なし。太い直線眉と大きい白目を持つ。主線は72dp換算2dp、補助線1dp。影は1段、背景・文字・光輪・気分色の枠は原画に描かない。根拠: 72dpで表情を読め、明暗テーマを同一画像で扱える。

| 部位 | 色・形 | 全差分共通条件 |
|---|---|---|
| 髪・衣装 | `#263544`、右分け、短い陣羽織 | 頭頂に二股の前髪（識別子I1） |
| 襟 | `#FFF1D5` | 中央に `#CDA452` の菱形留め＋黒い縦溝1本（I2） |
| 軍配 | 生成り `#FFF1D5`、柄 `#654A35` | 画面右下に水平線3本の面と握り手（I3） |
| 肌 | 基色 `#E8B88F`、影 `#C99070`、頬 `#C86E5C` | 汗・涙以外の色変更なし |
| 目・輪郭 | 虹彩 `#654A35`、白目 `#FFF9EF`、主線 `#24211E` | 目の位置と顔の輪郭を固定 |

実在人物、作品、家紋、ブランドに似せない。露出・流血・攻撃的な武器ポーズを描かない。笑いは自分の見栄の崩れに限定する。根拠: 軍師を怖い敵にせず、煽り返せる対等な相手にする。

## 差分5枚と暫定対応

| Mood.name | 表示名 | 目・眉・口・補助表現 | 暫定の顔文字 | 基準パス |
|---|---|---|---|---|
| `composed` | 平静 | 半開きの目、水平眉、閉じた片口笑い、汗なし | `(￣ー￣)` | `assets/gunshi/face_composed.webp` |
| `smug` | ドヤ顔 | 細い弧の目、上がる眉、開いた高笑い口、頬の赤み | `(≧▽≦)` | `assets/gunshi/face_smug.webp` |
| `rattled` | 動揺 | 見開く目、内側が上がる眉、歪んだ小口、画面左こめかみに汗1滴 | `(；´Д｀)` | `assets/gunshi/face_rattled.webp` |
| `meltdown` | 大混乱 | 小さな虹彩、左右不揃いの眉、縦に開く口、両頬に涙各1筋 | `(´；ω；｀)` | `assets/gunshi/face_meltdown.webp` |
| `coverUp` | 取り繕い | 視線を画面左へ逸らす、片眉を上げる、引きつる閉じ笑い、汗1滴 | `(・∀・;)` | `assets/gunshi/face_coverUp.webp` |

根拠: 目・眉・口の形で5種を区別でき、色を見分けなくても気分が分かる。`coverUp` の大文字Uを維持する。パスは `face_`＋`Mood.name`＋`.webp` と一意に結び付ける。

判定はコードが返すMoodをそのまま使う。優先順は `coverUp`（残り>0）→ `meltdown`（焦り≥0.75、または劣勢かつ冷静<0.3）→ `rattled`（焦り≥0.45、または冷静<0.45）→ `smug`（優勢かつ慢心≥0.5）→ `composed`。根拠: 数値をUIで再判定して違う顔を出さない。

| 追加候補 | 採否・表示 | 根拠 |
|---|---|---|
| 軍師勝利 | 専用絵なし、終局カード内のみ `smug` | 高笑いの用途を共有できる |
| 軍師敗北 | 専用絵なし、終局カード内のみ `meltdown` | 既存差分で落差が出る |
| 引き分け | 専用絵なし、終局カード内のみ `coverUp` | 逃げ切ったような取り繕いにする |
| エンジン思考 | 専用絵なし、現在のMood＋「一手を思考中」 | 思考は感情と直交する |
| LLM応答待ち | 専用絵なし、現在のMoodを保持 | 現行は定型文を即時表示し、待機状態を公開していない |
| 交渉 | 専用絵なし、現在のMood＋提案アイコン | 4交渉ごとの追加コストを作らない |

終局カードの顔は演出用の参照であり、MindState.moodを書き換えない。

## キャンバス・納品形式

| 項目 | 固定値 | 根拠 |
|---|---|---|
| 論理サイズ | 72×72dp、1:1 | 現行の差し替え口と一致する |
| 書き出し | 1x=72×72px、2x=144×144px、3x=216×216px | 標準～高密度端末を同一構図で扱う |
| 元データ | 864×864px、sRGB、レイヤー付きPSDを1個 | 3xの4倍で修正余地を確保する |
| ファイル | 透過WebP、ロスレス、全フレーム同じ原点・輪郭 | 白い縁とフェード時の位置ずれを防ぐ |
| セーフエリア | 中心(36,36)dp、半径30dpの円内に目・眉・口・I1/I2/I3を完全収容 | 半径36dpの円クリップに6dpの余裕を作る |
| 位置合わせ | 両目中心を(36,29)dp、顎下をy=48dp、襟留めを(33,55)dp、軍配中心を(52,47)dp | 差分で頭が跳ねない |
| 端の処理 | 外周2dpは完全透過、色付き半透明フリンジなし | 暗背景でも白縁を出さない |
| 上限 | 1x:16KiB、2x:40KiB、3x:80KiB、各Mood計136KiB | 圧縮後の容量を検収可能にする |
| 総容量 | ランタイム15ファイルで680KiB=696,320bytes以下、目標600KiB以下 | 5枚×3密度をすべて含める |

1KBを曖昧に使わず、本書は1KiB=1,024bytesとする。画像15個、原画PSD1個、権利表 `ASSET-LICENSES.md` 1個、目録 `manifest.csv` 1個の計18ファイルを納品する。目録列はパス・幅px・高さpx・バイト数・SHA256。原画と権利資料はアプリ容量に算入しない。

2xは `assets/gunshi/2.0x/face_{Mood.name}.webp`、3xは `assets/gunshi/3.0x/face_{Mood.name}.webp`。5種類をすべて同じ密度で揃える。原画のレイヤーは `base`（輪郭・髪・衣装・識別子固定）と `composed` / `smug` / `rattled` / `meltdown` / `coverUp`（目・眉・口・汗・涙の各差分グループ）にする。アプリでは合成済み画像を使い、パーツ合成・Live2D・動画は使わない。根拠: 納品時に表情を確定し、実装とランタイム負荷を小さくする。

## 表示・失敗時

| 状態 | 表示仕様 | 根拠 |
|---|---|---|
| ライト | 72dp円、背景 `#FFF1D5`、外周2dpはMood色 | 衣装の墨紺を分離する |
| ダーク | 同じ画像、同じ背景 `#FFF1D5`、外周2dpはダーク用Mood色 | 髪が背景に沈まない |
| 未納品・読込失敗 | 同じ円・同じ位置に表の顔文字、14sp、文字色 `#24211E` | レイアウトを変えず気分を伝える |
| 一部だけ失敗 | 該当Moodだけ顔文字へ置換 | 全体のロードを待たず対局を続ける |
| スクリーンリーダー | 「軍師、平静」等のラベルを1回読む、画像自体は装飾扱い | 顔文字の記号を逐語読みさせない |

顔文字は画像ファイルを偽装して作らず、同じ表示スロットの代替テキストとする。全画面で表示サイズ72dpを維持し、画像がまだなくても同じ受け入れ試験を行う。

## 遷移とリアクション

| トリガ | 演出 | 根拠 |
|---|---|---|
| Mood変化 | 180ms、easeOut、クロスフェード。途中の再変更は現表示から最新へ | 5気分の短い連続変化でも待ち行列を作らない |
| 同じMood | 常時の瞬き・呼吸なし、追加枚数0 | 盤を読む視線を邪魔せずデコード負荷を抑える |
| 冷静の実差分≤−0.15 | 顔レイヤーだけx=0→−3→3→−2→0dp、240ms、linear。各区間60ms | 強い煽りへの反応をゲーム盤から分離する |
| 差分>−0.15 | 揺れなし、[HUD](04-hud.md)の数値だけ | 小変化と強い効果を区別する |
| 動きを減らす | フェード0ms、揺れなし、状態ラベル即時更新 | 情報を残して動きだけ止める |

揺れは1回で終了し、再トリガは400ms間隔。同一イベントを再描画のたびに再生しない。盤・タップ領域は動かさない。

## 発注と検収

発注する絵はオリジナル制作とし、納品条件はCC0-1.0での提供、作者名・納品日・権利者・ライセンス全文への参照を権利表に記載する。第三者素材の混入は認めない。これは調達条件であり、未制作の画像の権利取得済みという意味ではない。

検収は5差分を72dpで横並びにし、識別子の欠落0、眼中心の差分間ずれ0px、円クリップによる必須部位の欠け0、ライト／ダークで白縁0、容量超過0を確認する。表情名を隠して5種を区別できることも発注者が確認する。画像失敗時は顔文字とラベルが残り、盤の操作に影響しないことを実装者が確認する。
