| 48dp | 盤マス自体の48dp達成は主張しない。360dp幅の自動試験と48dp以上の着手一覧を実装。SM S721Qでは盤のマス約44dp。ADBタップによる直接着手と一覧着手は成功。人が指で触った日常操作の受け入れは未実施。 |

| 口軽 | 取引中は標準HUDに口軽を戻す48dp行を追加。通常時は詳細に配置。取引中の360×640、文字1.3倍のレイアウトを試験。 |
