# ビジュアルシステム

この文書で確定したこと
- 木の盤・墨紺の軍師・生成りの紙面を基調にする。
- シード色は `#8D5524`、ライト／ダーク双方の文字と面を明示する。
- UI書体はNoto Sans JP、駒の文字描画は現状を維持する。
- 余白は4dp単位、操作部品の最小領域は48×48dpとする。
- 状態の変化は短いフェードと数値で伝え、盤は動かさない。

策定日: 2026-09-20。実装前仕様。関連: [表情](02-expressions.md)、[HUD](04-hud.md)、[画面と寸法](05-screens.md)、[音と触覚](06-feedback.md)。

## 方向性

「町の将棋道場で大げさな軍師と向き合う」を採用する。全面の古紙テクスチャ・金色の装飾枠・ネオンは使わない。根拠: 木の盤を主役にし、感情の変化を装飾で埋めない。対局画面に広告用の空白や未実装機能の枠を設けない。

### テキストのコントラスト契約

全テキスト4.5:1以上。WCAG相対輝度式で計算する（各sRGB成分cを0～1に正規化し、c≤0.04045ならc/12.92、他は((c+0.055)/1.055)^2.4、L=0.2126R+0.7152G+0.0722B、比=(L高+0.05)/(L低+0.05)）。

検査対象は①onSurface/onSurfaceVariantとsurface/surfaceContainer、②アクセント10行とsurface/surfaceContainer、③onSurfaceと3種の会話・提案面、④primary/onPrimary、⑤error/onError、⑥顔文字、⑦盤の文字と最暗木色。検査結果は本書末尾に記録する。半透明文字・文字のグラデーション・表にない背景との組合せは禁止する。根拠: 見かけだけのダーク対応を防ぐ。

現行 `#B8860B` / `#FFF9F0` と `#E67E22` / `#FFF9F0` は4.5:1未満なので、ラベル色として保持しない。旧色を比較するときは背景を明示し、単色だけに合否を付けない。

盤は既存の木色グラデーション `#F0CF8A` → `#E9C47A` → `#DDB05F` を両テーマで保持する。駒字の可読性は既存piece_painterを実描画で確認する対象であり、UIのコントラスト計算で検証済みとみなさない。

## タイポグラフィ

日本語UIはNoto Sans JP、400と700の2ウェイトを同梱する。ライセンスはSIL Open Font License 1.1（[公式配布のOFL.txt](https://raw.githubusercontent.com/google/fonts/main/ofl/notosansjp/OFL.txt)、2026-09-20確認）。フォント本体と著作権・OFL文を一緒に納品し、フォントのライセンスをGPLに書き換えない。根拠: オフライン・端末間で同じ寸法の日本語を表示する。

| TextThemeロール | sp | 行高倍率 | weight | 用途 |
|---|---:|---:|---:|---|
| displayLarge / Medium / Small | 32 / 28 / 24 | 1.25 | 700 | 終局結果（Smallのみ使用、他は予約） |
| headlineLarge / Medium / Small | 28 / 24 / 22 | 1.3 | 700 | 初回導入・画面見出し |
| titleLarge / Medium / Small | 20 / 16 / 14 | 1.4 | 700 | AppBar・節・カード名 |
| bodyLarge / Medium / Small | 16 / 14 / 12 | 1.5 | 400 | 全文・通常文・補足 |
| labelLarge / Medium / Small | 14 / 12 / 12 | 1.4 | 700 | ボタン・メーター・単位 |

文字間隔は全ロール0sp。UIは明朝にせず、駒の筆画と分離する。`piece_painter.dart` の文字・字体・比率を本仕様で変更しない。

OS文字倍率1.3では14sp本文の行高が27.3dp、12spラベルの行高が21.84dp。固定枠にはこの高さで入る行数だけ表示し、続きは全文領域へ送る。[05](05-screens.md)の寸法は1.3を含んだ値。通常の設定・説明は折り返して行高を増やす。1.3超はコンパクト配置＋縦スクロールの詳細領域を使い、文字倍率を強制的に下げない。

## モーション

| 対象 | duration / curve | 動きを減らすON | 根拠 |
|---|---|---|---|
| 表情（旧300ms） | 180ms / easeOut | 0ms | 変化を短く伝える |
| メーター（旧500ms easeOutBack） | 240ms / easeOutCubic | 0ms | オーバーシュートによる値の誤読を避ける |
| パネル開閉 | 180ms / easeOutCubic | 0ms | 視線移動を短くする |
| 数値差分 | 120ms fadeIn、保持1,480ms、200ms fadeOut | 固定表示1,800ms後に消す | 同じ領域で変化を読む |
| 表情の揺れ | 240ms / linear、[02](02-expressions.md)の変位 | なし | 盤の位置を保つ |
| 思考中の3点 | 400ms間隔で1→2→3→1、opacity固定 | 静止3点 | 進捗率を偽らず活動を示す |
| 着手先輪郭 | 即時表示、消去せず次の手で移動 | 同じ | 色だけに依存しない |

OSの動き低減がONなら必ず低減。アプリ設定は「OSに従う／減らす」で既定「OSに従う」。バックグラウンドでは装飾アニメーションを停止し、復帰時は最新状態のみ描画する。根拠: 過去イベントの再生を避ける。

## アクセシビリティの読み上げ

| 要素 | ラベル・規則 |
|---|---|
| 顔 | 「軍師、{Mood.label}」。気分が変わった時だけ通知 |
| メーター | 「冷静、80、100中」等。差分は「冷静、25減少」 |
| 盤 | 「7六、先手の歩、選択可能」等。空マスは座標＋空き。選択・合法な移動先を状態に含む |
| 持ち駒 | 「先手の持ち駒、歩、2枚、選択可能」 |
| 交渉 | 「軍師から提案。返答するまで着手できません」→全文→受ける→断る |
| 手番 | 「先手の番、王手」等。秒単位の時計更新を自動読上げしない |
| セリフ | 新規発話をpoliteで1回通知。LLM置換では自動再読しない |
| 非活性ボタン | 本文色を保ち「現在使えません、理由」を付ける |

通知の優先は終局→提案→王手→煽り→気分。連続変化は1,000ms内で最新1件に集約し、通常の盤読み上げを割り込ませない。

## 検証記録

2026-09-20、sRGB相対輝度の計算をPythonで実施。重複色をまとめた文字／背景23組ずつで、ライト最低5.703:1（`#914412`／`#F3E8D7`）、ダーク最低8.276:1（`#A8CADE`／`#252B32`）。顔文字は14.333:1。旧smug色は3.109:1、旧rattled色は2.721:1（いずれも背景 `#FFF9F0`）であり、置換理由を確認した。盤用の座標色 `#24211E`／最暗木色 `#DDB05F` は7.969:1。これは指定した不透明な色の組合せの計算値であり、アンチエイリアスや既存の駒字の実描画を測った値ではない。

配色の数値検査とレイアウト算術は文書作成時に実施する。Flutter実画面、フォント実測、TalkBack/VoiceOver、画像納品後の縮小検査は未実施であり、[05](05-screens.md)末尾の受け入れ項目として残す。
